# WinForge Roadmap · 路線圖

This roadmap covers the canonical .NET/WinUI 3 application. The experimental C++ port has its own roadmap in [WinForge-Native](https://github.com/codingmachineedge/WinForge-Native).

呢份路線圖只涵蓋正式 .NET／WinUI 3 app。實驗性 C++ 移植版嘅路線圖喺 [WinForge-Native](https://github.com/codingmachineedge/WinForge-Native)。

## Current priorities · 目前優先項目

- [x] Keep the managed Squirrel.Windows installer, portable build, updater contract, and release metadata aligned so the application always receives compatible `Setup.exe`/`RELEASES` updates; hosted stable release `v1.1.348` proves the source tip, timing, digests, and four required assets. · 保持受控 Squirrel.Windows installer、portable build、updater 合約同 release metadata 一致；hosted stable release `v1.1.348` 已證明 source tip、時間、digest 同四項必要資產互相對得上。
- [x] Add shared live settings, vault-backed School-mode unlock, the persisted emoji switch, opt-in serialized notification narration, an offline changelog viewer with regex/date filtering and export, persisted pinned tabs, and local TOTP pairing QR generation. · 加入共用即時設定、credential vault School mode 解鎖、保存 emoji 開關、選擇性序列化通知旁白、附 regex／日期篩選同匯出嘅離線變更紀錄、保存釘選分頁，同本機 TOTP 配對 QR 產生。
- [x] Add a versioned scheduled-settings editor and resolver with local values, validated HTTPS API values, Home Assistant boolean activation, timezone/date/time semantics, safe external refresh, and vault-backed tokens. · 加入有版本嘅排程設定編輯器同 resolver，支援本機數值、驗證 HTTPS API、Home Assistant boolean、時區／日期／時間語義、安全外部刷新同 vault token。
- [x] Add the local Support Tickets recovery desk with bounded persistence, status progression, local-only disclosure, and a non-destructive application-data-folder opener. · 加入本機支援工單復原台，有界保存、狀態流程、本機限定聲明，同非破壞性 application-data 資料夾開啟。
- [x] Add the complete bundled feature/wiki offline documentation browser with regex search and local article navigation. · 加入完整捆綁功能／wiki 離線文件瀏覽器、regex 搜尋同本機文章導覽。
- [x] Add the multi-entry local TOTP authenticator vault with Windows credential storage, current-code pairing confirmation, live list codes, search, reorder/group metadata, and redacted JSON/CSV exports. · 加入多項本機 TOTP authenticator vault、Windows credential 保存、目前驗證碼配對確認、清單即時驗證碼、搜尋、排序／群組資料，同刪密鑰 JSON／CSV 匯出。
- [x] Add the public-catalog dim-sum startup surprise: one fresh 10% draw after first usable layout per eligible launch, exact bilingual catalog names, three verified `catalog-v1*` release partitions, bounded HTTPS fetch, application-data image cache, non-blocking notification, and suppression during School mode, startup terms, deep links, and visible update/error work. · 加入公開 catalog 啟動點心驚喜：每次合資格啟動喺第一個可用 layout 後重新抽 10%、準確雙語 catalog 名、三個已驗證 `catalog-v1*` release partition、有界 HTTPS fetch、application-data 圖片 cache、非阻塞通知，同 School mode、startup terms、deep link、可見 update／error 工作抑制。
- [ ] Close the remaining universal surface audit: full search/menu regex coverage, tab locking/group discovery, appearance editing, QR image/camera ingestion, export/bulk actions, broader destructive-action migration, and the remaining tab/document surface work. · 補完 universal 介面審核餘下項目：全搜尋／menu regex 覆蓋、分頁鎖／group discovery、外觀編輯、QR 圖片／相機匯入、export／bulk actions、更廣泛破壞性動作遷移，同餘下分頁／文件介面工作。
- [ ] Continue the exhaustive managed feature audit: registered routes, deep links, page loads, control surfaces, service paths, companions, launchers, accessibility, and clipping. · 繼續完整審查正式 app 嘅 route、deep link、頁面載入、控制介面、service、companion、launcher、無障礙同裁切。
- [ ] Keep all three persisted language modes complete and usable at narrow widths: English, Cantonese, and bilingual. · 保持英文、粵語同雙語三種持久語言模式完整，並喺窄畫面仍然易用。
- [ ] Connect every search bar to the shared full Regex Builder, keep plain text as the default, and synchronize its pattern and supported flags bidirectionally with each real search operation. **2026-08-11 progress:** 14 builder-backed surfaces are shipped and the source inventory now covers 102 search/query controls across XAML and code-built surfaces; 67 applicable ordinary searches, 9 specialized dialects, and every remaining dropdown/menu/picker remain explicit migration work. The new-tab picker is now integrated and no longer belongs to the remaining ordinary-search count. · 將每個搜尋欄都接去共用完整版正則砌法，純文字繼續做預設，並同每個真實搜尋操作雙向同步 pattern 同支援旗標。**2026-08-11 進度：** 14 個已接 builder 嘅介面已交付，來源清單而家覆蓋 XAML 同 code-built 介面入面 102 個搜尋／查詢控制；67 個一般搜尋、9 個專用方言，同所有剩低 dropdown／menu／picker 仍然明確係整合工作。新分頁 picker 已經接好，唔再計入剩低一般搜尋數目。
- [ ] Migrate remaining non-decision page-local status surfaces to the shared notification centre, while retaining blocking dialogs only for confirmations, credentials, consent, and other choices that must finish before continuing. · 將餘下非決策 page-local 狀態介面遷移去共用通知中心；阻塞對話框只保留畀確認、憑證、同意，同其他必須先決定先可繼續嘅選擇。
- [ ] Finish the remaining rich-table and review-first UX work for device, package, archive, and other command-backed modules. · 完成裝置、套件、壓縮檔同其他 command-backed 模組餘下嘅豐富表格同先檢視後執行 UX。
- [ ] Expand safe import/export, configuration sync, diagnostics, and recovery while keeping secrets protected with DPAPI and destructive actions explicit. · 擴充安全 import／export、設定同步、診斷同復原，同時用 DPAPI 保護秘密，破壞性動作亦要明確確認。
- [ ] Continue AWS service-specific workspaces beyond native S3 and EC2: verified Cloud Control identifiers, live operations dashboards, and review-first controls for the next highest-value services. · 繼續將 AWS 專用工作區擴展到原生 S3 同 EC2 之外：加入已驗證 Cloud Control identifier、即時營運儀表板，同下一批高價值服務嘅先覆核控制。
- [ ] Preserve the reactor's 67-scenario engine/dependency gate, 10-test focused lifecycle gate, and safety invariants while extending simulation, companion, and integration coverage. · 擴充模擬、companion 同整合覆蓋時，保持反應堆 67 個引擎／相依服務情境 gate、10 項專項生命週期 gate，同安全 invariant。
