# Developer workflow workbench · 開發工作流程工作台

Open `WinForge.exe --page devterminal` for the review-first workbench above the existing Developer & Terminal quick actions.

用 `WinForge.exe --page devterminal` 開啟先審閱工作台；佢會放喺原有開發與終端機快捷操作上面。

## Workflows · 工作流程

- Resolve a bounded TCP port, review PID/name/address, confirm, then re-read the same port; any listener identity change blocks termination.
- Detect fnm, Volta, and nvm-windows; list/install versions, and open a genuinely version-scoped fnm/Volta PowerShell.
- Inspect/enable Corepack and prepare a validated pnpm or yarn channel.
- Pick, list, add, and remove reviewed Defender folder exclusions with protected-root rejection.
- Inspect then apply a validated dynamic TCP range and 30–300 second `TcpTimedWaitDelay`.
- Measure npm/pnpm/pip paths and show Docker `system df` before selected cleanup becomes available.

所有修改都有明確確認；提權只喺 Defender／TCP 真正套用時要求。輸入會用獨立 argv，檢視資料只留喺目前畫面。
