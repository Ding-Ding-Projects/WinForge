# Developer & Terminal workflows · 開發與終端機工作流程

This category contains the generated `dev.*` quick-action records and the maintained guide for the parameterized workflow workbench embedded at `WinForge.exe --page devterminal`.

呢個分類收錄自動生成嘅 `dev.*` 快捷操作記錄，同埋嵌入 `WinForge.exe --page devterminal` 嘅參數化工作台維護指南。

## HTTP/API disposition · HTTP／API 處置

These workflows call local Windows and developer CLIs and expose no HTTP API, so a Postman collection is not applicable. · 呢批流程只會呼叫本機 Windows 同開發工具 CLI，冇提供 HTTP API，所以唔適用 Postman collection。
