# New-tab picker search · 新分頁選擇器搜尋

The Ctrl+T and Add-tab picker uses WinForge's shared `SearchPatternBox`. Plain text is the default; the adjacent regex action opens the full bounded .NET builder with raw pattern editing, guided pieces, flags, syntax feedback, local preview, captures, and copy. · Ctrl+T 同 Add-tab picker 用 WinForge 共用 `SearchPatternBox`。純文字係預設；旁邊嘅 regex action 會開完整、有界 .NET builder，支援原始 pattern、引導組件、旗標、語法提示、本機預覽、capture 同複製。

The query searches the bilingual title, subtitle, key, and category labels. Category filtering composes with search. Empty queries preserve the normal frequent/suggested/category sections; a no-match or matcher-error state remains visible and named. Enter from the real query editor opens the first result, while Enter in the raw-pattern or sample fields does not close the picker; each result is a real keyboard-focusable button. Invalid patterns show validation and no results rather than silently changing the query. · 搜尋會查雙語標題、副標題、key 同分類標籤；分類篩選會同搜尋一齊生效。空 query 保留正常常用／建議／分類分段；冇結果或者 matcher error 會保留具名狀態。真正 query editor 按 Enter 開第一個結果，但 raw-pattern 或 sample 欄位按 Enter 唔會關閉 picker；每個結果都係真正可用鍵盤聚焦嘅 button。無效 pattern 會顯示驗證提示同零結果，唔會靜靜雞改走 query。

The category dropdown is its own keyboard-accessible `SearchablePickerBox`: its anchored `SearchPatternBox` searches category ids and bilingual labels, keeps plain text as the default, and reports invalid regex, matcher failure, and no matching categories in a named live status. Arrow keys navigate, Enter selects, Escape cancels, and the flyout returns focus to the category button without changing the selected object until a choice is committed. · 分類 dropdown 自己係可用鍵盤操作嘅 `SearchablePickerBox`：anchored `SearchPatternBox` 會查分類 id 同雙語標籤，純文字係預設，具名 live status 會報告無效 regex、matcher failure 同搵唔到分類。方向鍵導航、Enter 揀選、Escape 取消，而 flyout 關閉後會返 focus 分類按鈕；未確認選擇前唔會改已揀 object。

Patterns and samples stay in the current picker session. Local .NET matching uses the shared bounded timeout and size limits; no search text or sample is written to session exports, local history, telemetry, or network requests. · Pattern 同 sample 只留喺今次 picker session；本機 .NET matching 用共用有界 timeout 同大小限制；搜尋文字或 sample 唔會寫入 session export、本機 history、telemetry 或 network request。

Verification: `MainWindow.xaml.cs` wires separate `SearchPatternBox` and `SearchablePickerBox` controls; `tests/ShellAllAppsRoute.Tests` guards the category control's builder, matcher, no-match/error status, keyboard paths, and focus return, while the shared regex suite covers plain text, flags, invalid syntax, Unicode, captures, zero-width matches, timeout, and limits. · 驗證：`MainWindow.xaml.cs` 接入兩個分開嘅 `SearchPatternBox` 同 `SearchablePickerBox` control；`tests/ShellAllAppsRoute.Tests` 守住分類 control 嘅 builder、matcher、no-match／error status、鍵盤路徑同返 focus，而共用 regex suite 覆蓋純文字、旗標、無效語法、Unicode、capture、零寬配對、timeout 同限制。
