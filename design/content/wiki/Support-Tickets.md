# Support Tickets · 支援工單

Support Tickets is a local-only fictional recovery desk with bounded persistence, bilingual disclosure, status progression, extended bulk selection, complete selected-record exports, and a non-destructive application-data-folder opener. It never sends a ticket or deletes data for the user without the native two-key/full-slider confirmation. · 支援工單係本機虛構復原台，有界保存、雙語聲明、狀態流程、批量揀選、完整所選紀錄匯出，同非破壞性 application-data 資料夾開啟。未經本機兩條匙／完整滑桿確認，佢永遠唔會傳送工單，亦唔會代使用者刪資料。

The current contract test covers local persistence, ticket numbers, canned response, status progression, description bounds, and the no-delete recovery path. · 目前 contract test 覆蓋本機保存、工單號碼、罐頭回覆、狀態流程、描述限制同唔刪資料嘅復原路線。
