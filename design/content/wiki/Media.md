# Media · 媒體

![Media](https://raw.githubusercontent.com/codingmachineedge/WinForge/main/docs/screenshot-media.png)

**EN —** An ffmpeg/ffprobe media studio with quick conversions plus eleven guided production workflows: measured EBU R128, silence cleanup, two-pass stabilization, automatic black-bar crop, lossless multi-clip join, hardware-probed NVENC, target-size encoding, SRT/ASS subtitles, chapter splitting, HEIC/JXL photo batches, and EXIF/GPS privacy cleanup.

**粵語 —** ffmpeg／ffprobe 媒體工作台除咗快速轉檔，仲有 11 個引導式正式流程：量度式 EBU R128、靜音整理、兩步防震、自動黑邊裁剪、無損多片合併、實測 NVENC、目標容量、SRT／ASS 字幕、章節分割、HEIC／JXL 批次，同 EXIF／GPS 私隱清理。

All outputs are staged before promotion; file paths use argument vectors rather than a command shell; batches and chapter sets are bounded; and Cancel terminates the owned process and cleans owned scratch files. Full behavior, limits, failure modes, and 17-case verification are in the repository's `docs/features/media-capture/media-studio-workflows.md` guide.

所有輸出都會先暫存，成功先升格；檔案路徑用 argument vector 而唔經 command shell；批次同章節數量有上限；Cancel 會終止自家程序並清理自家 scratch 檔。完整行為、限制、失敗模式同 17 項專測喺 repository 嘅 Media 工作流程指南。
